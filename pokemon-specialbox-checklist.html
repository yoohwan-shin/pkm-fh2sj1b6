사용법 — 카드를 클릭하면 보유(회색 + 초록 체크) ↔ 미보유(컬러)로 전환됩니다. 상품 헤더의 미개봉 BOX 보유 버튼은 카드와 별개로 박스 자체의 보유 여부를 기록합니다. 카드 왼쪽 아래 🔍 는 고해상도 이미지를 띄웁니다.

상품 이미지는 각 상품 헤더 왼쪽에 있습니다. 클릭하면 크게 볼 수 있습니다. 名探偵ピカチュウ 점보 카드팩 두 상품만 패키지 사진을 못 구해서 동봉 점보 카드 이미지를 대신 넣고 그렇게 표시했습니다. マリオ / ルイージ 스페셜 BOX 두 상품은 아직 「상품 이미지 없음」입니다.

한국어 번역 버튼을 끄면 일본어 + 영문만 남습니다. 선택은 브라우저에 저장되어 다음에 열 때도 유지됩니다. 여기 실린 카드는 전부 일본판 전용 프로모라 한국판이 존재하지 않습니다. 한국어 줄은 어디까지나 읽기 편하라고 붙인 비공식 번역이며, 실제 카드에 인쇄된 이름은 일본어입니다. 검색창은 일본어 · 영문 · 한국어 어느 쪽으로도 찾을 수 있습니다.

가격은 전부 「정가」입니다 — 시세가 아닙니다

각 상품에 적힌 금액은 발매 당시 공식 희망소매가격을 그대로 옮긴 것입니다. 지금 거래되는 가격이 아닙니다. 절판된 상품은 대부분 정가를 크게 웃돕니다 — 예를 들어 トウキョーDX(정가 ¥2,600)나 カナザワ(정가 ¥5,104)는 중고 시장에서 수만 엔대에 거래됩니다. 구매 판단은 반드시 실제 시세를 따로 확인하고 하세요.

「+세」 표기는 원문이 세금 별도(本体価格)로 발표한 상품입니다. 2015~2016년 상품이 여기 해당하고, 2018년 이후 상품은 공식 표기가 세금 포함(税込)입니다. Pokémon GO 카드파일 세트와 名探偵ピカチュウ 점보 카드팩 2종은 공식 가격 표기를 확인하지 못해 「정가 확인 못 함」으로 뒀습니다.

같은 이름, 다른 카드 — 꼭 구분해야 하는 것들

カナザワのピカチュウ는 두 종류입니다. 147/S-P가 스페셜 BOX 봉입판, 144/S-P가 오픈 기간에 포켓몬센터·포켓몬스토어 방문객에게 나눠준 배포판입니다. BOX를 사야만 얻을 수 있는 147 쪽이 훨씬 비쌉니다. 144는 슬리브에 넣어 그냥 건네주는 방식이라 미개봉 개체가 존재하지 않습니다.

ヒロシマ는 박스가 두 번 나왔습니다. 2015년 오픈 기념(コイキングごっこ / ギャラドスごっこ)과 2025년 리뉴얼 기념(ヒロシマのピカチュウ)은 완전히 다른 상품입니다.

ヨコハマのピカチュウ는 네 장(280–283/SM-P)인데 280 · 281만 스페셜 BOX 봉입판이고, 282 · 283은 「潮風にのって」 캠페인으로 매장에서 배포한 것입니다. 같은 이름이라 섞이기 쉽습니다.

トウホクのピカチュウ도 88/SM-P와 260/SV-P 두 장이 있습니다. 스페셜 BOX 봉입판은 260 쪽입니다.

ポンチョを着たピカチュウ는 카드명이 전부 같습니다. 박스 봉입판은 207(メガリザードンX) · 208(メガリザードンY) · 230(レックウザ) · 231(黒いレックウザ) 네 장이고, 203 · 274 · 275는 여러 마리가 함께 그려진 캠페인 배포판이라 박스와 무관합니다.

박스가 아닌 것 — 배포 프로모

「배포 프로모」탭은 두 묶음입니다. 매장 배포 지역 한정은 シブヤ · オーサカDX · サッポロ · キョウト · オキナワ 처럼 지점 기념 카드는 나왔지만 박스 상품이 발매되지 않은 케이스이고, 구매 특전 · 동봉은 명탐정 피카츄 관련(영화 팸플릿 · 무비 스페셜팩 구매 특전 · Switch 조기구매 특전)과 YU NAGABA 콜라보 프로모입니다. 전부 박스를 찾아도 안 나오는 게 정상입니다.

25th ANNIVERSARY GOLDEN BOX — 카드는 나옵니다

전용 프로모는 없지만 박스 한정 카드는 있습니다. 동봉된 특제 피카츄 덱 60장이 15종(S8a-G)으로 구성되고, 전부 미러 킬라 사양이라 다른 곳에서 같은 사양을 구할 수 없습니다. 그 중 001/015 ピカチュウV가 카드 전체가 금색인 통칭 「골든 피카츄」이고, 002/015 モンスターボール도 골드 풀아트입니다. 피카츄 계열은 001 · 003 · 005 · 006 네 장(005는 001과 기술이 다른 별개 카드)이고 004는 ライチュウ입니다. 15종 전부 체크 대상으로 넣었습니다.

같이 들어 있는 프로모카드팩 25th ANNIVERSARY edition 5팩은 별개입니다 — 전 25종(S8a-P) 중 랜덤 1장이라 무엇이 나올지 정해져 있지 않고, 확장팩 25th ANNIVERSARY COLLECTION 4팩 구매 특전으로도 배포됐습니다. 25종 안에도 「ピカチュウ」가 있지만 박스 한정이 아니라 목록에 넣지 않았습니다.

YU NAGABA 이브이즈 스페셜 BOX — 이쪽은 정말 카드가 없습니다

공식 상품 구성이 덱실드 · 덱케이스 · 러버 플레이매트 · 카드박스뿐인 서플라이 전용 상품입니다. 나가바 유의 이브이 프로모 9종(62–70/SV-P)은 이 박스가 아니라 1,000엔 이상 구매 특전으로 배포됐고, 피카츄(208/S-P)는 2021년 1차 콜라보 구매 특전입니다. 셋 다 「배포 프로모」탭에 넣었습니다.

확장팩에서 나오는 카드는 넣지 않았습니다

여러 BOX에 확장팩이 같이 들어 있지만(카나자와 19팩, 히로시마 5팩 등) 그 안에서 나오는 카드는 랜덤이고 박스 한정도 아니라서 목록에서 뺐습니다. 이 페이지에 실린 것은 봉입이 확정된 박스 한정 카드뿐입니다.

목록을 어떻게 채웠나

스페셜 BOX는 공식 홈페이지에 상품 페이지가 남아 있지 않은 것이 많아 빠지기 쉽습니다. artofpkm.com의 상품 분류(Product type = Special Box)와 포켓몬별 상품 목록을 교차해서 훑은 뒤, 각 상품의 봉입 프로모를 공식 발표 · ポケブーン으로 하나씩 확인해 넣었습니다.

그 과정에서 걸러낸 것도 있습니다 — Pokémon GO 스페셜세트(¥3,700)는 봉입 프로모가 ミュウツーV라 피카츄 상품이 아니고, 仰天のボルテッカー / タッグボルト 포켓몬센터 한정세트는 부스터 박스와 서플라이 구성이라 봉입이 확정된 피카츄 카드가 없습니다. 패키지에 피카츄가 그려져 있을 뿐입니다. 셋 다 목록에서 뺐습니다.

데이터 출처

상품 구성·발매일·가격은 포켓몬카드 공식 홈페이지 상품 페이지 및 공식 뉴스, 우표 BOX는 일본우편 공식 발표. 카드 번호·이미지는 Limitless TCG 일본판 프로모 세트(XY-P / SM-P / S-P / SV-P). 어느 공개 DB에도 세트가 없는 S8a-G(골든박스 덱 15종)만 TCGplayer 상품 이미지를 씁니다. 상품 이미지는 공식 상품 페이지 · TCGplayer · Amazon.co.jp에서 가져옵니다. ポンチョ 계열 4종은 기술명과 카드 일러스트를 직접 대조해 지정했습니다. 일본판 전용 프로모라 공식 영문명이 없는 카드가 많아, 영문명 일부는 비공식 통용 표기입니다. 이미지 표시에는 인터넷 연결이 필요합니다.

아직 못 채운 것 — マリオピカチュウ / ルイージピカチュウ 스페셜 BOX 두 상품의 패키지 사진뿐입니다. 공식 상품 페이지가 남아 있지 않고 TCGplayer · Amazon에도 미개봉 상품이 없습니다. 두 상품의 봉입 프로모 카드(293–296/XY-P)는 정상적으로 나옵니다.
